摘要

一键把 YouTube 视频加入知识库

这个命令解决什么问题

当你看完一个 YouTube 视频的深度解读，生成了一整套中文知识包（字幕、翻译、分析、笔记、卡片），下一个问题总是：这些好东西存在哪？

散落在本地 outputs 目录里的文件，无法长期检索、无法与其他知识关联、无法自动发布。你还需要：

  • 手动复制文件到知识库
  • 手动写元数据
  • 手动更新索引
  • 手动提交推送

一键入库命令解决的就是这个"最后一公里"问题。

为什么需要一键入库

在 v0.3.18 之前，YouTube 视频解读工作流已经跑通了——输入一个链接，输出 11 个文件的知识包。但每次入库都是手工操作：

  1. 复制产物到知识库目录
  2. 写 metadata.yaml
  3. 整理 summary.md
  4. 写 notes.md
  5. 运行检查脚本
  6. 提交推送

这些步骤重复、机械、容易出错。更关键的是，解读和入库之间的时间差会导致：

  • 忘记具体哪些文件需要复制
  • 遗漏某个检查步骤
  • 格式不一致

一键入库把这些步骤固化成标准工作流，确保每次入库的质量一致。

它如何连接 OpenClaw 与 Hermes Knowledge Base

OpenClaw（解读层）        Hermes Knowledge Base（存储层）
        │                           │
youtube-brief ──解读──→ 产物目录 ──入库──→ content/articles/
        │                           │
        │                      build_index.py
        │                           │
        │                      GitHub Pages
        │                           │
        └────────── 可检索、可关联、可发布 ───────────┘

连接点：

  • 文件层面：产物目录的文件直接映射到知识库条目
  • 索引层面：build_index.py 自动把新条目加入 catalog.jsonl、tags.md、authors.md
  • 发布层面：update_site.py 自动更新 GitHub Pages 站点
  • 能力层面：知识库新增"YouTube Video Brief"能力说明，后续可检索复用

输入是什么

输入说明
视频解读产物目录YouTube Video Brief 的完整输出目录，包含 metadata.json、analysis.zh.md 等
目标仓库（可选）默认 ~/hermes-knowledge-base

前置条件：

  • 必须先完成 youtube-brief（视频解读）
  • 知识库仓库已 clone 且 remote 正确
  • 仓库状态 clean（无未提交修改）

输出是什么

视频知识库条目（4 个文件）

  • metadata.yaml — 知识库标准元数据
  • summary.md — 通俗文章，适合阅读和分享
  • notes.md — 结构化笔记，适合检索和复用
  • source.md — 来源和关联文档

能力说明条目（4 个文件）

  • 说明"YouTube Video Brief"是什么、能做什么、怎么用

同步文档（2 个）

  • docs/workflows/youtube-video-brief-workflow.md
  • docs/commands/youtube-brief-command.md

执行报告（1 个）

  • 记录完整入库过程、检查结果、commit hash、push 结果

适合哪些使用场景

场景说明
学习存档把看过的英文演讲/课程/访谈变成可检索的中文知识
写作素材库为文章、演讲、讨论准备结构化素材
研究追踪建立主题视频索引，支持跨视频比较
团队共享通过 GitHub Pages 自动发布，团队成员可直接访问
个人知识管理与 Hermes Knowledge Base 其他条目自然关联

与 v0.3.18 的区别

v0.3.18本命令（v0.3.19+）
定位单次入库手动操作标准化入库工作流
步骤分散、需记忆固化、可复用
检查手动运行脚本自动顺序执行
报告无标准报告标准报告模板
文档无 command 文档完整 workflow + command 文档
能力说明已有新增一键入库能力说明

后续可以如何扩展

  1. 自动扫描入库：自动检测 outputs/youtube-video-brief/ 中的新产物，提示批量入库
  2. 多平台发布：入库后自动生成小红书、公众号、Twitter/X 格式
  3. 语义关联：基于视频内容自动与知识库已有条目建立双向链接
  4. 播客化：从入库产物生成播客提纲和 TTS 朗读稿

一键入库，让知识从"生成"到"可用"只差一条命令。

命令名称

一键把 YouTube 视频加入知识库 — YouTube Video KB Import

核心流程

  1. 检查仓库状态（remote、分支、clean）
  2. 创建视频知识库条目（metadata.yaml + summary.md + notes.md + source.md）
  3. 同步 workflow / command 文档到知识库 docs/
  4. 新增知识库能力说明（YouTube Video Brief 能力文章）
  5. 执行检查脚本（check_kb.py → check_translation_residue.py → build_index.py → update_site.py）
  6. 生成入库报告
  7. 提交和推送

输入

  • 视频解读产物目录（YouTube Video Brief 输出）
  • 目标仓库（默认 ~/hermes-knowledge-base）

输出

  • 视频知识库条目（4 个文件）
  • 能力说明条目（4 个文件）
  • 同步文档（2 个文件）
  • 执行报告（1 个文件）

失败处理原则

  • 仓库 dirty → BLOCKED
  • 缺少产物文件 → BLOCKED
  • 检查脚本失败 → BLOCKED
  • push 失败 → BLOCKED

扩展方向

  • 多平台发布（小红书、公众号、Twitter/X）
