# 阅读笔记：10 Usability Heuristics for User Interface Design

## 一、接受（作者说服我的部分）

我接受这套原则作为“低成本、高收益”的设计审查工具。它不替代用户研究，但能快速暴露许多基础交互问题，尤其适合早期原型和内部工具。

## 二、反思（我仍存疑或需要补充的部分）

十条原则非常通用，应用时容易停留在口号层面。后续最好给每条原则补一个 Hermes KB 或实际产品案例，避免 checklist 变成形式主义。

## 三、联想（与其他文本 / KB 条目的呼应）

| 文本 / KB 条目 | 呼应点 |
