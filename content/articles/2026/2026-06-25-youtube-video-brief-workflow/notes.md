# 能力笔记：YouTube Video Brief

## 输入

- YouTube URL（支持标准链接、短链接、嵌入链接）

## 处理步骤

1. **获取 Metadata**
   - 标题、频道、时长、发布日期
   - 视频封面图

2. **提取字幕**
   - 优先级：人工英文字幕 → 自动英文字幕 → 其他语言字幕
   - 如无字幕 → BLOCKED，不擅自音频转写

3. **翻译字幕**
   - 保留原始时间戳
   - 分段翻译（通常 30-60 段）
   - 保留原文风格（幽默、讽刺、口语化）

4. **生成双语稿**
   - 英文 + 中文逐段对照

5. **生成深度解读**
   - 核心观点、关键概念、背景补充
   - 中国语境下的启发
   - 可操作建议

6. **生成分享文章**
   - 标题 ≤ 20 字
   - 结构清晰，有具体内容

7. **生成知识库入口**
   - 文件清单、推荐阅读顺序、适合谁读

8. **生成永久笔记**
   - 核心问题、观点、概念、可迁移方法

9. **生成知识卡片**
   - 10 张可复用卡片

10. **生成报告**
    - 执行过程、字幕来源、文件清单

## 输出文件清单

详见 summary.md 中的表格。

## 失败处理

| 场景 | 处理 |
|------|------|
| 无字幕 | BLOCKED，建议用户确认是否音频转写 |
| 需要音频转写 | BLOCKED，重型 Whisper 需用户授权 |
| 视频不可访问 | BLOCKED，建议检查网络或链接 |

## 最短命令

```
解读这个 YouTube 视频：https://youtu.be/VIDEO_ID
```

## 标准命令

```
请按照 youtube-video-brief-workflow.md 处理这个 YouTube 视频：https://youtu.be/VIDEO_ID
```

## 成功案例

Conan O'Brien 哈佛大学 2026 毕业演讲（24 分 53 秒）。完整产物见知识库条目：
`content/articles/2026/2026-06-25-conan-harvard-commencement-2026/`

## 注意事项

- 不登录 YouTube 账号
- 不读取浏览器 Cookie
- 不下载完整视频
- 无字幕时 BLOCKED
- 公开内容不暴露本地绝对路径
