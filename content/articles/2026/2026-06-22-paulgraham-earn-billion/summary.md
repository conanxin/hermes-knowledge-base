# 如何赚得十亿美元

## 一句话摘要

成为亿万富翁的路径只有两个数字——增速与时长——而它们都不需要作弊就能成立；政客之所以怀疑，是因为不懂指数增长的数学，把它当成"不可能的致富"；真正能持续高增速的创业，核心不是剥削而是同理心。

## 核心论点

1. **"赚十亿美元"涉及的两个数字都很平常**。一家公司从 200 万起步，以 93% 月增长，9.45 个月就能达到 10 亿级；即便保守到 15% 月增长，5 年内收入也会放大 4384 倍。靠作弊既不能提高增速，也不能扩大市场，所以"不作弊赚不到 10 亿"这个命题在数学上不成立。
2. **指数增长是"魔法般的"，也是被误读的根源**。政客看到"看似不可能的富有"就推测作弊，是因为不懂指数增长。一旦亲自算过 log(500, 1.93) ≈ 9.45 这种题，那种"魔法感"就消失了——剩下的只是两个可控数字的乘积。
3. **持续高增速的来源是用户口碑，而不是营销**。要让人们主动把产品告诉朋友，产品必须好到用户真心愿意推荐。这反过来要求创始人深入理解用户——而"理解用户"的最稳妥路径是"理解自己"。
4. **"做自己想用的东西"是发现未来需求的最优信号**。年轻人的需求预测未来的需求——你和你朋友现在用什么，10 年后所有人都会用。对"别人需要什么"的直觉通常很糟，对自己需求的直觉却很准。
5. **最好的创业点子不是"找"出来的**。刻意找点子会让你砍掉离群点。Apple、Google、Facebook、Airbnb、Twitch（Justin.TV）——这些当时听起来都很烂的点子，都不是"找"出来的，而是从"和朋友一起做酷项目"里自然生长出来的。
6. **创业的核心不是剥削，而是同理心**。同理心告诉你"用户真正想要什么、能怎样让他们的生活大幅变好"——这是 YC 寻找和培养创始人的核心标准。

## 关键概念速查

| 概念 | 定义 |
|------|------|
| **增速（growth rate）** | 决定创始人身价的"第一数字"。YC 创始人见面第一个问题必问增速，因为它直接说明"是否做对了产品" |
| **市场容量（market size）** | 决定创始人身价的"第二数字"。能增长 4000 倍，市场需求至少要有 4000 倍扩张空间 |
| **指数增长（exponential growth）** | 月增长 15% 即 1.15^60 ≈ 4384 倍，5 年内放大数千倍——这正是"看似不可能的富有"的来源 |
| **同理心（empathy）** | 深入理解用户真实需求的能力，YC 挑选创始人的核心标准，区别于"剥削式致富" |
| **未来需求信号** | 年轻人自己的需求与朋友的需求，会比"对别人需求的直觉"更准确地预测 5-10 年后的市场 |
| **离群点（outlier）** | 听起来"很烂"但实际上极具潜力的点子。刻意找点子最容易砍掉这类 |
| **滩头阵地（beachhead）** | 创业初期聚焦的极小目标用户群——以它为基础扩张到邻近市场 |

## 与其他文章的联系

- 与 **《超线性回报》（Superlinear Returns）** 是姊妹篇：那篇解释了"为什么绩效回报是超线性的"（指数增长 + 门槛），本文则把超线性回报**实操化**——把它落到"创业公司的增速"和"市场容量"两个具体数字上。
- 与 **YC 的"做无法规模化的事"原则** 直接对应：早期用户口碑引发指数增长，是本文的工程化版本。
- 与 **"如何做出伟大的工作"**：都强调"做你自己想要的东西"——本文扩展到"做你和朋友想要的东西"。
- 与 **"如何为创业想点子"（How to Get Startup Ideas）**：本文第 4-5 段是那篇文章的口语化版本，强调"不要找点子，去做酷项目"。

## 应用与延展

- **认知纠偏**：当看到有人快速致富时，先用"log + 月增长"算一下——多数"不可能的富有"其实只是指数曲线的中段。
- **创业判断**：每周自问"我的月增长是多少？过去 3 个月、6 个月、12 个月分别是多少？"——增速是你唯一该看的数字。
- **点子筛选**：当一个点子"听起来很烂"，不要立刻砍掉。问自己：它听起来烂，是因为它指向了一个尚未被命名的需求吗？
- **对政治叙事的解构**：当政治家/评论员说"那是不可能的"时，先做数学，而不是先接受道德判断——多数此类指控是指数增长扫盲失败的症状。
- **对青年创业者的建议**：做"你和朋友想要的东西"——这是被低估的、但被 YC 反复验证的"未来的需求"信号。
