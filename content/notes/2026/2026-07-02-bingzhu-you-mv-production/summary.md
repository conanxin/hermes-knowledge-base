# 秉烛游 · 一首从古诗出发的说唱与两分钟 MV

## 一句话总结

把汉乐府《古诗十九首》之十五的"生年不满百,常怀千岁忧"四句古诗,改写成 2 分 09 秒的中文说唱,配上四段 AI 生成的 6 秒场景、烧入歌词字幕与片头片尾,产出可在 Telegram 内联播放的 13 段小片段。**整条流水线由一个 AI 协作者(音乐模型 + 视频模型 + Hermes Agent 编排)完成,人类只写歌词与拍板。**

## 原始古诗(汉乐府《古诗十九首》之十五)

> 生年不满百,常怀千岁忧。
> 昼短苦夜长,何不秉烛游?
> 为乐当及时,何能待来兹?
> 愚者爱惜费,但为后世嗤。

诗的核心命题:**生命短暂,但人总是为遥不可及的未来焦虑,反而错过了当下的快乐**。解决方案是"秉烛游"——举着烛火在夜里出游,抓住眼前。

## 制作管线(七步)

| 步骤 | 工具 | 产物 | 关键参数 |
|---|---|---|---|
| 1. 歌词改写 | 人类 + AI 头脑风暴 | 上面 8 段中文说唱 | 押韵、节奏感、古诗原句保留为 hook |
| 2. 音频生成 | `music-2.6`(音乐模型) | `bingzhu_you.mp3` · 4 MB · 2:09 · 256 kbps | 风格 old school boom bap + 古风采样;BPM 88;A minor;男声说唱,带 chest voice + 轻微沙哑 |
| 3. 场景规划 | 故事板(人类 + AI) | 4 段 6s 场景,对应歌词结构 | A 举烛 / B 城市起舞 / C 金雨 / D 收束 |
| 4. 视频生成(并行 4 段) | A、D 用 `S2V-01`(subject reference);B、C 用 `Hailuo-2.3`(I2V) | 4 段 6s 720p mp4 | S2V 用封面作 subject image;B/C 用封面作 first frame |
| 5. 拼接到音频时长 | ffmpeg normalize + concat + loop | `final.mp4` 720×720 · 2:09 | 4 段循环叠加到 129s;libx264 crf 28 |
| 6. 烧入歌词字幕 | ffmpeg libass + ASS 字幕 | `final_subs.mp4` 14 MB | ASS 用 720×720 坐标系;Default 字号 40,Title 字号 72 金色 |
| 7. 加片头片尾 + 切段发送 | ffmpeg drawtext(textfile 避开转义坑) + 切片 | 13 段 mp4,每段 10.4s,≤ 1.4 MB | 片头 3s 标题+副标+鸣谢;片尾 3s "— 完 —"+ 鸣谢;分段每段 ≤ 1.4 MB 以适配 Telegram 通道 |

## 关键工程取舍

- **音频用 music-2.6 单次生成,不反复 prompt 调优** — 给定的风格描述(bpm/调式/人声/乐器)已经够具体,模型一次性给到满意结果。
- **视频分两路生成(S2V + I2V)**:A 和 D 必须保持书生形象一致,所以用 S2V-01 subject reference;B 和 C 是城市/金雨环境,不需要人物一致性,用 Hailuo-2.3 first-frame 模式更快。
- **完整 2:09 MV 不直接发 Telegram**:Bot 上传通道对几 MB 以上的 mp4 偶发超时。切成 13 段 ≤ 1.4 MB 之后稳定通过。
- **drawtext 文本用 `textfile=` 而不是 `text=`**:bash + Python 双层转义下,`text='中文'` 会被吞成黑帧。把每行文本写到独立文件再 `textfile=路径` 是稳的做法。
- **D 段(收束)在第一次生成时被配额拦了**:等到下个配额周期补做,rebuild 完整版,而不是降级用 3 段。

## 这件作品说明了什么

一件"从古诗到 2 分钟 MV"的活,**人类参与部分**:写 8 段歌词 + 拍 4 个关键决策(类型/状态/收录形式/链接形式)。**AI 参与部分**:8 个生成模型调用 + 6 步 ffmpeg 合成 + 1 个 Git push。**端到端耗时**:从写歌词到 13 段全发到 Telegram,**单次会话 ~3 小时**(含等待视频生成的等待时间)。

**与"AI 写作"或"AI 绘画"的不同**:这是 **AI 编排 + 多个专门模型分工** 的活,不是单模型"一气呵成"。**人类边界**在概念与拍板,**模型边界**在执行与生成,**Agent 边界**在工程与决策。三个边界清晰的边界让这件事**可重复**——任何人按这条 pipeline + 这套 prompt 都能产出一首类似质量的 MV。
