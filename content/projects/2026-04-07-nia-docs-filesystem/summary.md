# 摘要：Nia Docs — 把整个 Web 变成文件系统

## 原始内容讲什么

Nia Docs 是 Nozomio Labs 提出的解决 AI Agent 代码幻觉问题的方案。核心洞察是：代码幻觉是数据问题（API 每天都在变，模型训练数据滞后），而非模型问题。Nia Docs 通过将文档网站转换为文件系统抽象（URL → 文件路径），让 Agent 用天生的文件系统操作（tree/grep/cat）来浏览文档，而不是依赖复杂的 MCP 工具或碎片化的 RAG 检索。

## 为什么值得迁移

- **解决真实问题**：Agent 代码幻觉是普遍痛点，Nia Docs 提供了优雅的解决方案
- **架构创新**：文件系统抽象 vs MCP/RAG 的对比有深刻洞察
- **技术实现完整**：包含 Index/Serve/Shell 三层架构和 API 设计
- **与当前知识库关联**：与 Wiki vs RAG 分析、Karpathy Second Brain 等形成知识网络

## 迁移后如何使用

- **技术参考**：设计 Agent 文档系统时引用
- **架构对比**：在评估 RAG/MCP/文件系统方案时作为案例
- **产品灵感**：如果开发类似工具，可直接参考实现
- **概念教学**：向他人解释"为什么文件系统抽象优于 MCP"
