## Metadata Cleanup 线是否建议暂停

**是，建议暂停。**

理由：
1. 五轮迭代后 WARN 从 38 降至 24（-36.8%），边际收益递减
2. 剩余 24 WARN 的 tag 结构较为合理，强行合并可能引入语义损失
3. 当前 24 WARN 属于 `PASS_WITH_WARNINGS`，不影响正常使用
4. 应优先设计 tag policy / allowlist 机制，而非继续手工合并
