### Notes on the 5 verifications

- **#53 Jorge Ben — `Jorge Ben Jor - Topic`**: UMG Content ID auto-generated
  Topic channel. Description confirms: "Provided to YouTube by Jorge Ben
  Samba Esquema Novo ℗ 1963 Universal Music Ltda Released on: 1963-01-01
  Producer: Armando Pittigliani". 1963 Philips Records (Brazil) canonical
  recording from album *Samba esquema novo*. Note: the canonical artist name
  is "Jorge Ben" but the Topic channel is named "Jorge Ben Jor - Topic" (the
  "Jor" suffix was adopted by the artist in 1989; the 1963 original release
  credits "Jorge Ben"). This is a UMG Content ID convention where the
  current legal name is used for the Topic channel.

- **#66 Herbie Hancock — `Herbie Hancock - Topic`**: UMG Content ID auto-generated
  Topic channel. Title: "Cantaloupe Island (Remastered 1999/Rudy Van Gelder
  Edition)". 1964 Blue Note Records canonical recording from album *Empyrean
  Isles*. Musicians: Herbie Hancock (piano), Freddie Hubbard (cornet), Ron
  Carter (bass), Tony Williams (drums). Recorded June 17, 1964 at Van Gelder
  Studio. The 1999 Remaster is the same 1964 recording with a Rudy Van Gelder
  24-bit digital remaster applied — the original 1964 mix is the canonical
  version.

- **#67 Joni Mitchell — `Joni Mitchell - Topic`**: Rhino/Warner Content ID
  auto-generated Topic channel. Description confirms: "Provided to YouTube by
  Rhino/Warner Records Cactus Tree (2021 Remaster) · Joni Mitchell The
  Reprise Albums (1968-1971) ℗ 1968 Rhino Entertainment Company, a Warner
  Music Group". 1968 Reprise Records canonical recording from album *Song to
  a Seagull*. The 2021 Remaster is the same 1968 studio recording with Matt

  version. The paste-headline year 1968 matches the studio recording year.

- **#86 Bill Evans & Jim Hall — `Bill Evans - Topic`**: UMG Content ID
  auto-generated Topic channel. 1962 United Artists Records canonical recording
  from album *Undercurrent* (later Blue Note 1988 reissue, now UMG). The

  Van Heusen, but this is the canonical Evans-Hall duo 1962 studio recording.
  Note: the canonical credit is "Bill Evans & Jim Hall" but the Topic
  channel is named "Bill Evans - Topic" (no Jim Hall) — this is a UMG Content
  ID convention where the leader artist name is used for the Topic channel
  auto-generation.

- **#95 Eric Dolphy — `Eric Dolphy - Topic`**: UMG Content ID auto-generated
  Topic channel. Description confirms: "Provided to YouTube by Universal
  Music Group Hat And Beard · Eric Dolphy Blue Monk (Blue Note Plays Monk's

  The 1994 *Blue Monk* compilation release reuses the original 1964 *Out to

  the compilation/album context differs.

## Channel Verification Methodology

For all 5 new embeds, channel authenticity was verified using two methods:

1. **YouTube oEmbed API** (no browser, no proxy required) — returns
   `author_name` + `author_url` for any public YouTube video. Used to confirm
   the channel handle/name matches the artist or label.

2. **Cross-check against YouTube description metadata** — the Topic-channel
   auto-generated audio tracks include a `Provided to YouTube by [Label]` line
   in the description, e.g. "Provided to YouTube by Rhino/Warner Records
   Cactus Tree (2021 Remaster) · Joni Mitchell The Reprise Albums (1968-1971)
   ℗ 1968 Rhino Entertainment Company, a Warner Music Group". This metadata
   is Copyright-Content-ID-mediated, so it is reliable.

3. **For remasters**: when the canonical master is available only as a
   remaster on YouTube (e.g. *Cantaloupe Island* 1999 RVG Remaster, *Eric
   Dolphy* 1994 Blue Monk compilation, *Joni Mitchell* 2021 Reprise Remaster),
   the original recording is the same; the remaster is just an audio-quality
   upgrade of the same canonical master. The note explicitly clarifies the
   year mapping and the remaster relationship.
