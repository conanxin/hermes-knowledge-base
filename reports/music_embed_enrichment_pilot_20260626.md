## 6. check_tracks.py 增强

按 v0.3.20 任务规范第 5 步,最小增强 `scripts/check_tracks.py`:

### 6.1 verified 条目必须满足:
1. 至少一个可播放 URL(`youtube_embed_url` / `spotify_url` / `apple_music_url` 任一非空)
2. `note` 字段必填(非空字符串,必须记录验证依据)

### 6.2 增强实现

在 `validate_tracks_file()` 函数末尾追加(v0.3.20 新增):

```python
# v0.3.20: verified tracks must have at least one playable URL and a note.
if conf == "verified":
    has_yt = bool(t.get("youtube_embed_url", "") or "")
    has_spotify = bool(t.get("spotify_url", "") or "")
    has_apple = bool(t.get("apple_music_url", "") or "")
    if not (has_yt or has_spotify or has_apple):
        issues.append(
            f"{label}: confidence=verified but no playable URL "
            f"(youtube_embed_url/spotify_url/apple_music_url all empty)"
        )
    note = (t.get("note", "") or "").strip()
    if not note:
        issues.append(
            f"{label}: confidence=verified but note is empty "
            f"(must document verification source per MUSIC_ARTICLE_RULES)"
        )
```

并在 main() 的 STATUS 输出中区分:

```python
if conf_counts.get("verified", 0) == 0:
    print("STATUS: WARNING — no tracks with confidence=verified; all require human URL review")
else:
    print("STATUS: PASS — verified tracks present, with_playable_urls checked")
```

### 6.3 兼容性
- 0 verified 状态:`STATUS: WARNING` (旧行为)
- ≥1 verified 状态:`STATUS: PASS` (新)
- 任何 verified 缺 URL / 缺 note:`STATUS: FAIL` with explicit reason

### 12.2 验证流程(每首)

1. **web_search**:"Artist" "Title" "official" + site:youtube.com
2. **看 search 描述**:确认 channel name 是 artist official / Topic / label official
3. **排除 cover / live / reaction / karaoke / lyric video**(除非有充分理由 + note 说明)
4. **填 5 字段**:`youtube_url` + `youtube_embed_url` + (可选 `spotify_url`/`apple_music_url`) + `confidence: verified` + `note` (含验证依据)
5. **跑 check_tracks.py**:确认 STATUS PASS 且无 new issues
6. **跑 update_site.py**:重生成 detail page
7. **curl /items/...**:确认 play button 出现 + data-embed-url 正确

### 12.3 避免的失败模式

- ❌ 选 lyric video 当 verified(必须选 Topic channel 的 canonical recording)
- ❌ 漏 note 字段(`check_tracks.py` 会在 confidence=verified 且 note 空时报 FAIL)
- ❌ 漏 youtube_embed_url(必须是 `https://www.youtube.com/embed/<ID>` 格式)
- ❌ 把 spotify_url / apple_music_url 留空也 PASS — 但 note 必须说明 "Spotify/Apple Music URLs not verified in this pilot - left empty"

### 12.4 速度预估

- 每首 search + 验证 + patch 约 1-2 分钟
- 5 首 pilot: 实际耗时约 8-10 分钟(含多次 search 和 verification)
- 全 50 首:约 1-2 小时(分散到 v0.3.20.x / v0.3.21 / v0.3.22 多个小版本)
- **建议每批 5-8 首**,在 STORY ARCHITECT 角度平衡 pilot 验证速度与版本号颗粒度
