## New Capability

Added ordinary web article import:

```bash
python3 scripts/web_article_to_kb.py --url "<URL>" --dry-run
python3 scripts/web_article_to_kb.py --url "<URL>" --import
```

Optional local test modes:

```bash
python3 scripts/web_article_to_kb.py --html-file "<path>" --dry-run
python3 scripts/web_article_to_kb.py --markdown-file "<path>" --dry-run
python3 scripts/web_article_to_kb.py --text-file "<path>" --dry-run
```

The script writes capture JSON to:

```text
inbox/raw/web/YYYY-MM-DD-<slug>.json
```

Real imports write standard article files under:

```text
content/articles/YYYY/<slug>/
```

with:

- `metadata.yaml`
- `source.md`
- `translation.zh-CN.md`
- `summary.md`
- `notes.md`
- `raw_payload.json`

## Supported Web Types

Supported:

- public HTTP(S) article pages
- pages where visible body text can be extracted from `article`, `main`, schema.org Article/NewsArticle JSON-LD, OpenGraph/Twitter metadata, common content containers, or body fallback
- Chinese articles as translation mirrors
- English articles with a legal placeholder translation draft marked as needing review

Not supported / hard-stop:

- login, cookie, scan-code, paywall, or access-restricted pages
- robots.txt disallowed URLs
- pages whose full body requires authenticated JS state
- incomplete text, title-only pages, summaries, or clearly truncated content
- WeChat, YouTube, or PDF routes disguised as generic web input

## Dedup Strategy

The web route checks duplicates before writing new content:

1. `source_url`
2. `canonical_url`
3. `title + source_site + published_date`
4. `content_hash`

Duplicate inputs return `SKIPPED_DUPLICATE` with `duplicate_of` populated and do not write new KB entries.
