## Channel Verification Methodology

For the 1 new embed, channel authenticity was verified using two methods:

1. **YouTube oEmbed API** (no browser, no proxy required) — returns
   `author_name` + `author_url` for any public YouTube video. Used to confirm
   the channel handle/name matches the artist or label.

2. **Cross-check against YouTube description metadata** — the Topic-channel
   auto-generated audio tracks include a `Provided to YouTube by [Label]` line
   in the description. This metadata is Copyright-Content-ID-mediated, so
   it is reliable.

3. **For remasters**: when the canonical master is available only as a
   remaster on YouTube (e.g. *What Is and What Should Never Be* 2012 Remaster),
   the original recording is the same; the remaster is just an audio-quality
   upgrade of the same canonical master. The note explicitly clarifies the
   year mapping and the remaster relationship.

## Why This Batch is Small (1 vs 4-6)

This batch was constrained by the **strict no-hard-fill policy** the user
instructed in this round:

> "如果找不到高置信来源,继续 defer,不要硬填"

Of the 18 needs_verification candidates, the only one with a confirmed
high-confidence YouTube Topic source verified via the oEmbed API + label
metadata cross-check was **#75 Led Zeppelin**. The remaining 17 candidates
either:

1. Have no YouTube Topic / VEVO / official-label channel available
   (most common case for 1960s catalog material pre-YouTube era).
2. Have only fan-upload / vinyl-rip archives (would require fan-channel
   whitelisting, which user rules explicitly disallow).
3. Have live-performance-only canonical sources where the studio Topic
   doesn't exist (e.g. Blind Faith's BBC Hyde Park 1969).

Future batches (v0.3.28+) will continue searching for high-confidence
sources for these 17 candidates; if found, they will be added; if not,
they will continue to be deferred rather than filled with low-confidence
content.

## Operational Note

This batch demonstrates the value of the strict-defer policy: by
deliberately shipping only 1 verified embed instead of padding the
batch to 4-6 with weak sources, the verified rate remains meaningful
(each verified entry is a genuine high-confidence Topic source). The
4-6 range in the spec is described as "目标" (target) not a hard
minimum, and the explicit no-hard-fill instruction takes precedence.
