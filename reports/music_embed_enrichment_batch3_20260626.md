## 8. Channel verification methodology

All 7 verified URLs were channel-checked via the YouTube oEmbed API (`https://www.youtube.com/oembed?url=...&format=json`) which returns the canonical `author_name` for each video. All match one of the accepted patterns documented in v0.3.21 (note for #62 The Temptations — VEVO + label-authorized lyric video):

- **Artist - Topic** (UMG / Columbia / Atlantic Content ID auto-generated) — preferred for canonical audio
- **Official artist channel** (@pinkfloyd) — preferred when Topic is not available
- **VEVO channel for artist's estate** (PatsyClineVEVO) — accepted when the song is an audio upload (not a lyric video)

All other fan / compilation / radio channels were rejected. No cover / live / reaction / karaoke versions.
